# 공개 출처

`params/*.yaml`의 숫자가 기대는 공개 자료. 숫자 옆 note에는 짧게 적고, 링크와 날짜는 여기에 모은다.
기사의 수치는 그 시점 값이다. 실제 조선소의 값을 그대로 쓰지 않고, 범위를 보고 가상 조선소 값을 정한다(근거 등급 "가정").
