# ADR-013 재생 속도와 정답 로그 상한

- 상태: 확정
- 날짜: 2026-10-27

## 맥락

방출기는 정답 로그를 읽는 대로 보내서 5년치가 몇 초 만에 토픽에 들어간다. 배치는 상관없지만, 플랫폼의 소비 지연 경보(5단계)와 스트림 뷰(7단계)는 메시지가 실제 시간에 걸쳐 들어와야 의미가 있다.
실제 시간으로 오래 돌리려면 방출기가 끝없는 정답 로그(`sim --forever`, ADR-004)를 따라 읽어야 한다. 그런데 `sim --forever`는 속도 제한 없이 가상 5년을 몇 초에 써서 30분 안에 10GB를 넘긴다.

## 결정

1. **속도는 가상 초 대 실제 초**: `--speed N`이면 가상 N초 = 실제 1초다. 1440이면 가상 하루 = 실제 1분, 5년 ≈ 실제 30시간. 시뮬레이터와 방출기가 같은 `sim/pace.py`(`Pacer`)를 쓴다. 처음 부른 가상 시각과 그때의 실제 시각이 기준이고, 실제 시간보다 앞서지 않게 기다린다. 늦으면 기다리지 않고 따라잡는다.
2. **방출기는 도착 시각(`emitted_at`)에 맞춰 보낸다**: 노이즈로 정한 도착 순서와 간격이 그대로 실제 시간이 된다. 메시지 내용과 순서는 속도가 없을 때와 같다. 기다리기 전에 사본(`--copy-dir`)을 비워, 재발행 서비스의 처리 시각(ADR-012)이 지금을 따른다.
3. **시뮬레이터도 속도를 맞추되 하루 앞선다**(`sim --speed N --lead-days 1`): 가상 10분마다 엔진을 멈춰 기다리고, 기다리기 전에 정답 로그를 비운다. 방출기는 정답 로그가 그 도착 시각을 지나야 메시지를 내므로, 정답 로그가 앞서 있어야 방출기가 제때 보낸다. 10분 박자는 이벤트를 내지 않아 다른 이벤트의 순서는 그대로다.
4. **방출기는 정답 로그를 따라 읽는다**(`--follow`): 끝에 닿아도 멈추지 않고 1초마다 새 줄과 새 날짜 파일을 기다린다. 줄바꿈으로 끝나지 않은 줄은 쓰는 중이라 읽지 않는다(재발행처럼 따라 읽지 않는 쪽도 같다). 다음 날짜 파일이 보이면 앞 파일은 닫힌 것이다(시뮬레이터는 다음 날 파일을 열기 전에 앞 파일을 닫는다). 체크포인트에서 이어 읽는 것(ADR-007)은 그대로다.
5. **정답 로그 상한은 10GB**(`sim --max-gb`, 기본 10): 이번 실행이 쓴 바이트가 상한에 닿으면 그날까지 쓰고, 다음 날 이벤트가 나올 때 멈춘다. 지우는 것은 없어 체크포인트와 재발행이 그대로 된다. 방출 사본은 크기가 비슷하지만 플랫폼의 착륙 구역(ADR-007)이라 세지 않는다.
6. **compose**: 기본(`docker-compose.yml`)은 지금처럼 5년을 한꺼번에 보낸다. 실시간은 `docker-compose.live.yml`을 겹쳐 쓴다. sim `--forever --speed 1440`, emitter `--follow --speed 1440`이다.

## 결과

- 확인: 호스트에서 `--speed 86400`(가상 하루 = 1초)으로 20초 돌리자 정답 로그는 11/23, 방출 로그는 11/22까지 나아갔다(하루 앞섬). compose 실시간으로 75초 돌리자 정답 로그 11/04, 방출 로그 11/03이었고 Kafka 토픽에 들어왔다.
- 1440이면 정답 로그는 실제 하루에 약 20MB(5년 25MB) 늘어, 10GB까지 1년 넘게 걸린다. 상한은 속도 없이 `--forever`를 돌릴 때를 막는다.
- 완료 기준은 `tests/sim/test_pace.py`, `tests/sim/test_reader.py`, `tests/emitter/test_speed.py`가 보인다: 기다리는 시간과 앞섬, 박자를 넣어도 같은 이벤트, 상한에 닿은 날까지만 씀, 쓰는 중인 줄을 건너뛰고 새 줄·새 날짜를 따라 읽음, 속도를 줘도 같은 방출 로그.
- 다루지 않는 것
  - 시뮬레이터 이어 돌리기. `sim`을 다시 켜면 처음부터 다시 쓴다. 실시간 실행 중에는 `sim`을 다시 켜지 않는다.
  - 방출기가 멈췄다 다시 켜졌을 때 실제 시간으로 따라잡기. 다시 켠 때가 새 기준이라, 멈춘 만큼 늦게 간다.
  - 상한에 닿은 뒤 방출기에 끝을 알리기. 방출기는 계속 기다린다.
